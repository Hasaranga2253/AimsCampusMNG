# Database Design

## Overview
The AIMS data layer is planned for PostgreSQL with Prisma used later for schema management and database access.

## Current Status
Database models, migrations, and Prisma configuration are not implemented yet in this repository foundation phase.

## Planned Core Areas
The future schema is expected to cover users, programmes, modules, enrolments, timetables, attendance, assessments, moderation workflows, and academic results.

## Design Goal
The database design will prioritize clear academic relationships, auditability, and maintainable module boundaries between business domains.
